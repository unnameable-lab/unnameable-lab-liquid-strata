## Liquid Strata — 積もる生命 ／ 地層の習作

**▶ デモ：** https://unnameable-lab.github.io/unnameable-lab-liquid-cosmos/liquid-strata.html

上でコンウェイのライフゲーム（B3/S23）が動き、下端の帯にいるセルが砂になって落ち、地層として積もっていく習作です。Liquid Cosmos と同じ形式（1ファイル・WebGL・録画つき）で作っています。

- **堆積**：帯にセルがいた位置にだけ積もる。セルが居つく所は山に、来ない所は谷のまま残る
- **阿蘇の筋書き**：大火砕流（Aso-1〜4）とカルデラ陥没、カルデラ湖、湖の決壊、中央火口丘の成長が、決まった世代で順に起きる
- **岩の色**：古い溶岩流（柱状節理・クリンカー）、溶結凝灰岩、黒ボク・ローム・軽石、湖成層、スコリア
- **地下水**：染みこんだ水が水を通しやすい層を選んで左（熊本の側）へ流れ、澄んで湧き出す
- **世代の目盛り**：右端に100世代ごとと事件ごとの目盛り
- **音**：曲の低音で出水と噴火の強さが変わる
- **操作**：上をなぞると種まき、下をなぞると地層を削れる。早送り（×4・×16）、録画、没入表示

阿蘇の変遷をなぞった筋書きで、年代や実際の地形・水の流れを再現したものではありません。

`liquid-strata.html` を開くだけで動きます（外部ライブラリなし・曲も埋め込みの1ファイル）。
